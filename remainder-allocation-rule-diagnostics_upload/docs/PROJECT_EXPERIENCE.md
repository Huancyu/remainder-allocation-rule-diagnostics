# 项目经历

## 项目名称

生产余数放量规则诊断与优化项目

## 项目角色

项目负责人 / 数据分析与规则优化负责人

负责业务问题拆解、数据口径定义、数据质量排查、预处理流程设计、统计诊断模型开发、规则效果评估、业务报表与交互式可视化交付，并协调业务与数字化部门确认数据源和上线边界。

## 项目描述

针对生产订单长期沿用固定余数规则、部分规则放量过多或覆盖不足的问题，基于历史订单的领进数量、报工数量、系统余数、规格、计划数量和工艺信息，搭建从数据预处理、补单版本链识别、异常样本剔除、规则诊断到业务报表输出的完整分析流程。

项目首先在滚镀、挂镀和五金组装三个车间建立三维规则诊断框架，随后结合业务要求，将表面处理工序的规则细化为“余数编号×数量区间×规格区间×镀种大类”。以“领进数量－报工数量”定义实际损耗，通过P90/P95方案评估覆盖率和正向多余余数变化；当镀种子组样本不足时，回退使用三维父组分位数。同时建立规则调整优先级，并输出Excel决策清单与可离线查询的交互式实际损耗分布页面。

## 项目业绩

- 建立覆盖取数核验、通用预处理、补单关联、规则诊断和报表验收的标准化工作流，将分散的人工分析沉淀为可重复执行的程序。
- 第一阶段累计分析三个车间约28.3万条原始订单记录，形成“数值调整、规则细分候选、无需调整、样本不足”的分层诊断框架。
- 识别并统一余数编号与中文类别混用、系统标准历史变更、百分比与数量定额混算等口径问题，减少规则错配和样本误分组。
- 建立“订单号×检验层型号×订单版本”补单版本链，关联补数原因和补数大类，并将质量类补单从正常损耗样本中剔除。
- 通过跨版本数据对比和MOM核验，定位Tableau最小领进数量异常归零问题，推动正式损耗口径改为“领进数量－报工数量”，避免数据源异常误导规则调整。
- 在滚镀最新批次中完成10.19万条原始记录、8.36万条有效样本和1,451个四维子规则诊断；P95方案在总体覆盖率由95.04%调整至94.41%的情况下，预计减少16.16%的正向多余余数。
- 以P90-P95构建损耗参考带，根据系统余数均值相对参考带的位置提出上调、下调或维持建议，并结合偏离程度、样本可信度和预计影响设置复核优先级。
- 开发Excel规则清单和交互式HTML损耗分布报告，支持规则编号检索、筛选、P99尾部说明、鼠标悬停查看区间及父组/子组P90、P95口径识别。

## 简历精简版

**生产余数放量规则诊断与优化｜项目负责人**

围绕生产订单系统余数配置过量或覆盖不足问题，主导搭建从数据取数核验、CNT及补单版本链关联、异常样本剔除、规则诊断到Excel/交互HTML交付的完整分析流程；将规则由三维扩展为“余数编号×数量区间×规格区间×镀种大类”，使用P90/P95评估覆盖率与正向多余余数，并设计样本不足父组回退及调整优先级机制。累计分析三个车间约28.3万条历史记录；滚镀最新批次覆盖8.36万条有效样本和1,451个四维子规则，P95方案在总体覆盖率仅下降0.64个百分点的情况下，预计减少16.16%的正向多余余数。
