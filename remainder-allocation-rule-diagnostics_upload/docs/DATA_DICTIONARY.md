# 样例数据字典

| 字段 | 说明 |
|---|---|
| 样本ID | 合成数据的唯一编号 |
| 余数编号 | 规则类别编号 |
| 数量下限/数量上限 | 系统规则的计划数量区间 |
| 规格下限/规格上限 | 系统规则的规格区间 |
| 定额单位 | 数量或百分比 |
| 镀种大类 | 四维规则的强制分类字段 |
| 余数 | 订单实际使用的系统余数数量 |
| 领进数量 | 生产领进数量 |
| 报工数量 | 生产报工数量 |
| 计划数量(不含余数) | 不含系统余数的订单计划数量 |
| 实际损耗 | 领进数量减报工数量 |
| 是否进入分析 | 通用预处理后的审计标记 |
