# 数据安全

本仓库仅允许提交通用分析代码、方法文档和合成样例数据。

禁止提交：

- 真实订单号、合同号、CNT、物料名称和检验层型号；
- 客户、供应商、员工或组织信息；
- 生产数量、补单明细和质量原因原始记录；
- 数据库地址、库表结构、SQL取数文件、账号或Token；
- 由真实订单级数据生成且能够反推业务信息的明细结果。

公开前请执行：

```powershell
git status --short
git diff --cached
git grep -n -I -E "订单号|合同号|树形CNT|检验层型号|数据库|password|token|secret"
```

若需要保存真实数据和真实业务报表，请使用公司批准的私有代码托管与数据存储方案。
