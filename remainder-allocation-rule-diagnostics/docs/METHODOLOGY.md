# 方法说明

## 1. 分析目标

在控制覆盖率和补单风险的前提下，识别系统余数放量过高、过低或内部差异明显的规则，并为业务提供P90/P95两个调整参考档位。

## 2. 核心口径

```text
实际损耗 = 领进数量 - 报工数量
覆盖率 = 余数 >= 实际损耗的订单占比
正向多余余数 = Σ max(余数 - 实际损耗, 0)
实际损耗率 = 实际损耗 ÷ 计划数量(不含余数) × 100%
```

正向多余余数逐单截断为0后再汇总，不允许高损耗订单的负值抵消其他订单的多余余数。

## 3. 规则层级

三维父规则：

```text
余数编号 × 数量区间 × 规格区间
```

四维子规则：

```text
余数编号 × 数量区间 × 规格区间 × 镀种大类
```

数量定额组使用实际损耗数量计算分位数；百分比定额组先计算逐单损耗率，再计算分位数。

## 4. 小样本处理

- 子组样本量达到30：使用子组P90/P95。
- 子组样本量不足30：使用对应三维父组P90/P95。
- 父组分位值应用到子组订单后，重新计算该子组的覆盖率和正向多余余数。
- 小样本规则的优先级乘以可信度折扣，避免被排到业务复核前列。

## 5. P95减少比例

```text
当前正向多余余数
= Σ max(订单余数字段 - 实际损耗, 0)

P95方案正向多余余数
= Σ max(P95方案余数 - 实际损耗, 0)

P95预计减少比例
= (当前正向多余余数 - P95方案正向多余余数)
  ÷ 当前正向多余余数
```

系统基准使用每张订单实际的余数字段。图表中的父组系统余数均值线只用于展示，不作为总体收益计算基准。

## 6. 数据质量控制

正式项目中执行的主要检查包括：

- 订单类型、核销标记和暂停标志；
- 系统规则是否匹配；
- 计划数量、领进数量、报工数量和余数是否有效；
- 实际损耗是否为负；
- 大批量订单是否进入特殊业务流程；
- 是否属于质量类补单；
- 镀种大类是否成功映射；
- 表面处理车间是否存在异常高损耗率；
- Tableau或数仓字段是否与MOM/数据库源数据一致。

## 7. 输出

- Excel：规则维度、样本量、父组系统余数均值、P90/P95、预计减少比例、覆盖率、判断来源和优先级。
- HTML：实际损耗直方图、父组系统均值线、子组或父组P90/P95线、查询导航、P99尾部说明和悬停提示。
